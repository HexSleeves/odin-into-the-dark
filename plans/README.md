## Dependency notes

- **002 requires 001**: 001 commits the in-flight atomic-write + `.bak`-recovery
  work and removes its debug cruft. 002 is a third structural change to the save
  format; it must start from a clean, committed, recovery-capable baseline so its
  drift check is meaningful and the round-trip tests are the safety net.
- **003 and 004 are independent** of the save plans and of each other; they can
  run in parallel with 002.
- **004 is sequencing-sensitive to save size**: a ~3.9 MB save base64-encodes to
  ~5.2 MB, over the typical localStorage quota. Prefer running 004 *after* the
  save-size reductions (002 + the deferred present-floors-only / compression
  follow-ups), or use IndexedDB. Flagged inside the plan.
